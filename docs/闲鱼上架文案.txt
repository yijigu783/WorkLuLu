【先说清楚】
这个软件本身是开源免费的，在开源社区和吾爱破解都能免费下载到，
我不瞒着。你如果自己会找，搜 "WorkLuLu" 就能拿到，不用花这个钱。

我这里收的费用，对应的是：帮你准备好可以直接双击就用的版本、
一份写清楚怎么用的说明、以及后面用的时候有问题随时来问我。
你要是觉得自己下载配置没问题，就不用拍，我把地址发你也行。

【它能干什么】
· 记工作：标题、分类、备注、子任务（最多三层），可以勾进度
· 存模板：一套流程（含各层步骤）存一次，下次顶栏点一下就挑模板一键重建
· 定期限：支持每天 / 每周（选周几）/ 每月（选哪天）/ 每季度，自动算下次时间
· 会提醒：到点弹系统通知，点一下直接跳回那一条
· 看全局：列表、看板、日历三种视角随时切
· 好查找：搜索，按分类和状态筛
· 数据自己拿着：可以备份成一个文件、随时恢复、也能导出表格
· 可贴边隐藏：拖到屏幕边缘就滑到一边只留一条窄边，鼠标碰一下再滑回来
· 可做便携版：数据能放到程序旁边的 data 文件夹，整个文件夹拷到 U 盘就走

【和云笔记不一样的地方】
· 单文件 4MB，免安装，拷到 U 盘就能带走，换电脑不用重装
· 数据可以跟着程序走（便携模式），也默认存在本机用户目录，两可
· 数据全部存在你自己电脑上，不上传、不采集、不需要注册账号
· 没有广告、没有弹窗、没有捆绑、没有后台常驻
· 关掉窗口就缩到托盘，不占内存

【适合谁】
不想用云笔记、又需要定时提醒的人。电脑上记琐事、例行工作、
周期性事务安排都合适。

【需要改成你自己要的样子？】
上面说的是标准版本。如果你想要一版换成你们公司的名字、字段和
你们自己的业务对得上、或者去掉用不上的模块，可以私聊说需求，
我按改动量给你报价（一般 50-200 元），单独给你做一版。

【发货方式】
拍下后在闲鱼聊天窗口发货，我发下载地址和使用说明。

【运行环境】
Windows 10（1809 及以上）/ Windows 11，64 位。
依赖系统自带的 WebView2 组件，Win10 1809 之后的系统基本都自带。

【五】定制版：报价与接单流程
════════════════════════════════════════════════════════════════

 报价梯度（照着谈就行，别现场拍脑袋）
 ────────────────────────────────────────────────────────────────
   轻度 · 50-80 元
     换软件名、换品牌文字、换配色、换图标
   中度 · 80-150 元
     改默认分类、改字段名称和术语、去掉用不上的模块、
     预置好他们常用的分类和提醒规则
   重度 · 150-300 元
     加功能、改交互、对接他们的业务流程，按需评估

 报价前必须问清三件事，否则一定返工：
   1. 具体改哪里（让他一条条列，别听「你看着改」）
   2. 要不要保留原来的名字和开源版本的信息
   3. 交付前留几天给你改（一般报 3-5 天，别报太紧）

 接单流程
 ────────────────────────────────────────────────────────────────
   1. 买家私聊说需求 → 你确认改动点、报价、报工期
   2. 买家【在闲鱼上下单】→ 绝不能私下转账（平台红线，也是你的保障）
   3. 你改好 → 发给他试用 → 他确认没问题
   4. 他确认收货

 必须先收钱再改。定制的最大风险是你改完了买家不要了，
 闲鱼没有「收定金」这个环节，所以要么全款下单，要么不做。

【六】做定制要避开的两个坑
════════════════════════════════════════════════════════════════

 坑一 · 以为源码是你的护城河，其实不是
 ────────────────────────────────────────────────────────────────
 你的源码已经在 GitHub 上公开了（MIT）。也就是说，任何会编译的人
 都能自己下载下来改，不需要找你。

 这不影响你做生意，但要认清你卖的是什么：
   ✗ 不是「只有你能改」（会编译的人都能改）
   ✓ 而是「他懒得自己改」（装 Rust、配环境、编译失败排错，
      对一个普通用户来说门槛很高）

 所以：定制版的客户一定是「不会自己编译的普通人」。懂技术的人
 不会买你的定制，去找他们也没用。价格天花板受这个限制，别指望
 卖到几百上千。

 交付时默认只给 exe，不用给源码。但要知道，你不给源码这件事
 保护不了你什么——源码本来就在 GitHub 上。

 坑二 · 别承诺「只做给你一个人」
 ────────────────────────────────────────────────────────────────
 同行业的两家客户可能提几乎一样的需求。你要是答应了独家，
 第二单就得推掉。文案里写「按你的需求单独做一版」就够了，
 不要写「不会给别人同一份」。

 另外如果他要拿公司名和 logo 做进去，让他自己确认有使用授权，
 你只负责改软件，不替他的商标背书。

【八】这些词千万别写
════════════════════════════════════════════════════════════════

 × 「绿色版」——闲鱼语境里这个词经常和破解关联，容易被判违规。
    改用「免安装」「单文件」。
 × 「破解」「免激活」「激活码」——直接红线。
 × 「永久」「终身」「包更新」「不过退款」——平台的违禁词过滤，
    拼多多已经明确禁止，闲鱼同样敏感。
 × 「一手货源」「七天无理由」——会触发「职业卖家」判定，
    被认定后要办营业执照，还被强制七天无理由退货。
 × 「加微信 / 加 QQ 群领更新」——平台红线，严禁引导站外交易。
    所有沟通和交付都留在闲鱼聊天窗口里。
 × 夸大承诺，比如「数据永不丢失」——出一次问题就是纠纷。

【九】「支持后续更新」这件事的现实
════════════════════════════════════════════════════════════════

 闲鱼的虚拟商品交付是一次性的（聊天窗口 / 网盘链接），
 没有给老买家持续推送新版本的通道。想做的更新只能靠：

 · 买家主动来问你，你手动发新版 —— 可行，但需要你长期在线响应
 · 建群统一发 —— 平台严禁引导加微信 / 群，这条路走不通
 · 软件自己做云更新 —— 更新地址是公开的，谁拿到地址就等于拿到软件，
   等于放弃收费。要做就得配激活码 + 授权服务器，那是另一个量级的工作。

 所以文案里不要承诺「持续更新」，改成「有问题随时问我」，
 这是你能真正兑现的。

 定制版反而没这个问题：定制是一次性交付，本来也不需要后续更新。
