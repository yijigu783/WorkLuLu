────────────────────────────────
一、这是什么
────────────────────────────────

一个纯本地的个人工作记录工具，把日常要做的事分成三类：

  · 一次性 —— 哪天要干完的临时活（比如"周五前把报价单发出去"）
  · 周期性 —— 按固定节奏重复的动作（每周五交周报、每月 1 号对账）
  · 阶段性 —— 要持续一段时间的项目，可以拆成子任务逐条打勾

和常见待办 App 的区别在两点：

  1. 周期性工作不需要"做完一次再手动建下一条"，由排期引擎自动算出下一次时间；
  2. 阶段性工作看的是"结束日期"而不是"开始日期"，所以刚起步的项目不会被一路标红。

所有数据存在本机 SQLite 数据库，程序不联网、不上传、不采集。


────────────────────────────────
二、三类工作，各自的时间口径
────────────────────────────────

  一次性    填一个截止时间，到点提醒一次。适合临时任务、交差办事。
  周期性    设一条规则，之后自动排期。适合周报月报、例会、对账。
  阶段性    开始日 + 结束日，中间可以拆子任务。适合项目、专项、学习计划。


────────────────────────────────
三、周期规则支持四种频率
────────────────────────────────

  · 每天     到点提醒一次
  · 每周     周一到周日任选，可多选（比如每周一、三、五）
  · 每月     自己挑 1~31 号。选 31 号表示"月末"，遇到 2 月这类小月
             会自动落到当月最后一天，不会整月跳过
  · 每季度   先选从哪个月起算，再选几号。
             锚点 3 月 → 排在 3 / 6 / 9 / 12 月
             锚点 1 月 → 排在 1 / 4 / 7 / 10 月

每种频率都可以单独设提醒时间（比如 17:00）。


────────────────────────────────
四、提醒
────────────────────────────────

  · 到点弹 Windows 系统通知
  · 点通知直接跳回那一条工作（不是只把窗口叫起来）
  · 托盘右键可以「暂停到期提醒 / 恢复到期提醒」，
    开会或休假时不用去改任务本身

如果通知没弹出来，先检查「设置 → 系统 → 通知」里是否放行了本程序，
以及「专注助手（勿扰模式）」是否开着。


────────────────────────────────
五、窗口行为与托盘常驻
────────────────────────────────

  【贴边自动隐藏】设置里可开，默认关

    · 把窗口拖到屏幕左边缘或右边缘松手，它会滑到屏幕外，只留一条窄边
    · 鼠标碰一下那条窄边才滑回来（得先从旁边离开过一次，所以不会刚收起就弹回去）
    · 鼠标移开窗口一会儿再自动收回去
    · 从任务栏或 Alt+Tab 把窗口叫回来时，也会自动滑回来

    默认关是有意的：拖窗口贴边是很自然的动作，默认开的话，用户某天只会
    发现"窗口不见了"，还看不出是自己拖出去造成的。这个开关只改变窗口怎么摆，
    不写注册表、不动数据。

  【拖到边缘自动分屏】设置里可开，默认开

    · 拖到屏幕左/右边缘松手 = 半屏；拖到左上/右上角 = 四分之一；拖到顶部 = 最大化
    · 和上面的贴边隐藏抢同一条屏幕边，所以两个开关只能开一个，
      打开的会顶掉另一个（设置页会直接说明）

  【托盘常驻】

    右键菜单：打开主窗口 / 今天待办（N）/ 新建工作 / 暂停·恢复到期提醒 / 退出
    悬停提示和菜单里都直接显示今天有几件待办
    左键点托盘图标 = 打开窗口并切到「今天」

    关闭窗口默认收进托盘继续在后台跑，提醒不会因为关了窗口而失效
    （这条可以在设置里关掉）

八、模板：不重复手建同一套结构
────────────────────────────────

一件事只要变成"每周/每月都要走一遍的流程"，手建就成了负担——先建父任务，
再一条条加子任务，逐条排日期。模板就是为这个准备的。

  怎么存    打开任意一条工作的详情，点"存为模板"，起个名字。
            它会连同下面的各层步骤一起存进模板库（侧栏"模板"）。
  怎么用    顶栏点"从模板"，就地列出全部模板，挑一个；再选基准日，
            整批就按模板里的相对天数铺开。
            （模板页的卡片上也有"一键新建"，两处走的是同一条路）

顶栏那个入口是就地挑、挑完直接接选日期，不用先切到模板页再在卡片里找——
对"这套流程今天就要走一遍"来说，少一步就是少一次打断。

关键设计：模板里存的是"相对第几天"，不是具体日期。

    整理材料    第 0 天开始，第 4 天交
    对齐数据    第 0 天，第 1 天交
    出结论页    第 3 天，第 4 天交

存"10 月 8 日截止"的话，下个月调用时就是一堆过期任务；存"第 4 天截止"，
什么时候调用都成立。时分也一并留住，不会还原成默认时间。

另外：

  · 删模板不影响已经建出来的工作
  · 模板里的分类如果被删了，那一条会落到"未分类"，而不是拦下整批
  · "复制一份"是轻量版：连步骤带日期整体平移复制，适合"这件事下个月还要再做一遍"


────────────────────────────────
九、附件：把聊天截图直接粘进来
────────────────────────────────

工作里的"留痕"大多是截图——微信上对方说了什么、系统里报了哪个错、
邮件里承诺的哪个日期。以前只能另存到文件夹再手动记路径，记着记着就找不到了。

现在在工作的详情里直接 Ctrl+V 就贴进来了：

  粘贴    复制好截图，在详情里按 Ctrl+V。也可以直接把文件拖进窗口，
          或者点"选择文件"（图片、PDF、Word、压缩包都行，单个上限 20 MB）
  查看    图片点开铺满整屏看细节，Esc 关掉；其他文件交给系统默认程序打开
  留痕    挂了附件的条目，列表和看板上会有一个小标记带着张数，
          不用逐条点开就知道哪条有据可查

关键设计：附件存在数据库里，不是存成一堆散文件。

这不是为了省事，是为了让"备份 = 一个 .db 文件拷走就是全部数据"这条不变式继续成立。
散文件的话，备份就得是"库 + 附件目录"两样东西，用户漏拷一半是迟早的事——
而漏掉的那一半恰好是留痕。现在备份照旧一个文件，附件跟着一起走、一起恢复。

代价是 .db 会变大，所以贴进来的图片会先在本地压一道：

  · 原图长边超过 2200 像素才缩，日常截图基本不触发
  · 优先存 PNG 无损——聊天截图全是文字，JPEG 的块效应会把字边糊掉，
    糊掉的截图做留痕就没意义了
  · 只有 PNG 压完还超过 4 MB 才退回 JPEG（质量 0.9）
  · 列表里只取 360 像素的缩略图，几千张也不会卡

另外：

  · 删掉工作，它的附件一并删掉——附件是这条工作的证据，工作没了证据也就没有归属
  · 新建工作还没保存时粘的图会先暂存，点"创建工作"时一起入库
  · 从模板建出来的工作不带附件（模板存的是结构，不是某一次的证据）

────────────────────────────────
十一、备份、恢复与导出
────────────────────────────────

设置页里管数据的有这几个按钮：

  · 备份数据
    导出成一个独立的 .db 文件，拷到 U 盘或网盘都行。附件（截图、文件）也在里面，
    所以备份仍然是"一个文件拷走就是全部数据"，不需要额外打包附件目录。
    用的是 SQLite 的 VACUUM INTO，而不是直接复制文件 —— 库跑在 WAL 模式下，
    直接复制有可能漏掉还留在 -wal 里没并回主文件的改动，而且这种缺失是
    悄无声息的：文件能打开、表也在，等真要用的时候才发现少了最近几天。

  · 从备份恢复
    选中备份文件后完全替换当前数据。这件事不可逆，所以：
      - 恢复前自动把现在的数据另存一份到 backups 文件夹，选错了还能切回来
      - 恢复过程整体放在一个事务里，要么全成、要么原样不动
      - 备份文件会先校验（四张表在不在、列数对不对得上），
        不是本程序导出的、或者版本对不上的，直接拒绝，不会恢复出一半

  · 导出为 CSV
    存成表格，Excel / WPS 直接打开。带 UTF-8 BOM，中文不乱码。


────────────────────────────────
十二、绿色说明：程序会写哪些地方
────────────────────────────────

单文件 exe，双击即用，不需要安装，也没有注册表关联、没有服务、没有开机启动项
（除非你自己在设置里打开自启）。

程序会在本机写这两处，都可以随时手动删除：

  1. %APPDATA%\工作记录本\
     存放数据库 worklog.db，也就是你的全部记录。
     删掉这个文件夹 = 清空数据。

  2. %APPDATA%\工作记录本\backups\
     从备份恢复数据之前，自动留下的当前数据快照。
     可以随时删，删了只是在「恢复选错文件」时少一层退路。

  3. HKCU\Software\Classes\AppUserModelId\com.local.worklog
     一个通知标识，作用是让系统通知的标题显示「工作记录本」而不是 exe 文件名。
     删掉不影响使用，只是通知标题会变回文件名。

注意：数据不在 exe 所在目录，所以 exe 可以随便挪位置、放 U 盘，数据不受影响。

想让数据跟着程序走（整个文件夹拷到 U 盘就能带走），打开**便携模式**即可：

  · 怎么开    设置页「数据存放位置」点「切为便携模式」；也可以在 exe 同级放一个
              空的 portable.txt，或者建一个名为 data 的文件夹。下次启动会把
              现有数据整体搬过去，位置是 <exe目录>\data\
  · 会搬什么  数据库本体 + 它旁边的 wal / shm 临时文件 + backups 快照文件夹
  · 安全      动手之前自动留一份快照；程序装在只读位置（Program Files、只读 U 盘）
              会明确拒绝并说清原因，不会偷偷退回用户目录
  · 关掉      用同一个按钮切回标准模式；手工关的话要同时去掉 portable.txt 和 data 目录
  · 例外      便携模式只搬数据。上面第 3 条那个通知标识仍然写在注册表里 ——
              不写的话系统通知会顶着 exe 文件名出来

触发刻意做成「必须显式」：程序不会自作聪明地检测 exe 目录能不能写就切过去。
真那样做的话，从别人手里拿到一个 exe、丢到 D 盘双击，就会打开一个空库 ——
看起来就像数据全丢了，而且完全看不出原因。


────────────────────────────────
十三、已知限制（先说清楚，省得踩坑）
────────────────────────────────

  · 没有标签功能，目前只有分类 + 搜索
  · 只有浅色主题，没做深色模式
  · 子任务最多拆三层（工作 → 子任务 → 子子任务）。再深对"工作记录"这个场景
    没有实际意义，只会让缩进和进度统计一起变复杂
  · 模板只存结构和相对日期，不带"已完成"状态：从模板建出来的一律是新的待办
  · 老版本（1.0.x）建的备份里没有模板数据，恢复那种备份时不会动你现有的模板
  · 只支持 64 位 Windows 10 (1809+) / Windows 11。不支持 Win7，因为底层框架本身
    已停止支持 Win7，不是我偷懒省事
  · 需要系统的 WebView2 运行时。Win11 和打过较新补丁的 Win10 都自带；
    如果双击后没反应，装一次微软官方的 WebView2 Evergreen Runtime 即可
  · 备份要手动点，没有自动定时备份
  · 恢复是整体替换，不能合并两份数据
  · 便携模式只搬数据，不搬注册表里的通知标识和开机自启项
  · 附件存在数据库里，所以 .db 会比纯文字数据大。粘贴的图片已自动压过一道，
    但长期大量存截图的话，.db 还是会慢慢涨（设置页能看当前体积）
  · 单个附件上限 20 MB，超过会被拒绝
  · 从模板建出来的工作不带附件——模板存的是结构，不是某一次的证据
  · 贴边隐藏靠鼠标碰一下露出的那条窄边唤醒（要先从旁边离开一次，免得刚拖过去
    就自己弹回来）；窄边被别的窗口压住时，从任务栏或 Alt+Tab 叫它回来也一样有效
  · Windows 自己也有「拖到屏幕边缘自动分屏」，那是系统层的行为，
    和软件里的开关无关；本软件的分屏开关只是把同样的手感补到位，两者不冲突

────────────────────────────────
附二：被误报、或提示"未知发布者"怎么办
────────────────────────────────

（发帖后一定会有人在回复里问到，这段可以直接贴出去）

先说清两件常被混在一起的事：

  · 杀毒软件把它当病毒删掉、隔离 —— 这才是"误报"。未签名的个人开发程序
    在国内几家启发式引擎下比较常见，尤其新版本刚发布的时候。
  · 双击时弹出蓝色的「Windows 已保护你的电脑」—— 这不是杀毒，是 SmartScreen
    的信誉拦截。它只看两点：程序有没有数字签名、这个文件被下载过多少次。
    新发布的文件天然过不了这道门槛。点「更多信息」→「仍要运行」就行。

本人没有购买数字签名证书（个人开发者的证书一年要上千元），所以上面两种情况
都可能遇到，不是文件有问题。下面是应对办法。

一、加进信任区（设一次就行）

  360 安全卫士   主界面 → 木马查杀 → 右下角「信任区」→ 添加文件
                  建议勾上「按文件路径信任，文件内容变化后该条目不失效」，
                  这样以后更新版本不用再加一遍
  360 杀毒       右上角「设置」→ 文件白名单 → 添加文件
  Windows Defender
                  Windows 安全中心 → 病毒和威胁防护 → 管理设置 →
                  排除项 → 添加排除项 → 选这个 exe（或它所在的文件夹）
  火绒           主界面 → 防护中心 → 信任区 → 添加文件
  腾讯电脑管家   病毒查杀 → 信任区 → 添加文件

二、帮我把误报反馈给厂商（可选，但很管用）

  反馈时附上 VirusTotal 和微步在线的自查结果，审核会快很多：

    · VirusTotal   https://www.virustotal.com/
    · 微步在线      https://s.threatbook.com/

  各家提交入口：

    · 微软 WDSI    https://www.microsoft.com/en-us/wdsi/filesubmission
                   （类型选 Software developer - false positive）
    · 360 开放平台  https://open.soft.360.cn/report.php
    · 火绒          https://bbs.huorong.cn/forum-59-1.html
    · 腾讯电脑管家  https://txc.qq.com/products/415334/faqs-more/?id=128301

三、核验文件没被二次打包

  对照帖子顶部的 MD5 / SHA1 / SHA256。Windows 自带 PowerShell 算一行就行：

    Get-FileHash .\WorkLuLu-工作记录本-1.6.0.exe -Algorithm SHA256
